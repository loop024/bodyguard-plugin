# BodyGuard 全面改良計画 — 読み始める場所

作成日: 2026-09-20。対象: このリポジトリの Spigot 1.21.8 / Java 21 版。

## 提案の結論

「護衛を集める」から「分隊ごとに指示し、止まった理由まで分かる」プラグインへ改良する。保存の整合性、操作の統一、役職保護の安定化を土台に、分隊・個人設定・追従の詰まり対策を追加する。

既存コードを一括で書き直さず、既存の入口を残して内側を小さく置き換える。Lunaへは一度に1チケットを渡す。モデルに関係なく完全無欠な実装は保証できないため、曖昧な仕様を減らし、差分と完了条件を明確にする方針である。

## 改良の順序

1. **P0 / 安定化**: 保存形式6の不整合、新形式を誤復旧しない処理、設定の一括反映、操作結果の正確化、役職切替後の古い攻撃対象の排除。
2. **P1 / 使いやすさ**: 管理と画面の責務分離、個人設定、役職選択画面、状態と原因の統一表示。
3. **P2 / 操作の拡張**: 最大8分隊、分隊ごとの追従・待機・警備・回復・集合、負荷を分散した一括処理。
4. **P3 / 移動と運用**: 歩行の詰まり検出、安全な復帰、処理量の制限、診断と運用文書。

スキルツリー・装備強化・自動蘇生・経済連携・共有所有・Web管理画面は今回の実装範囲に含めない。既存の保存・所有権・Minecraft標準戦闘との関係を大きく広げるため、基盤完成後の別計画とする。

## 現時点で行ったこと

この文書は全面改良の構想を記録したもの。現在の実装状況は [直近の改善計画](REMAINING_IMPROVEMENTS_PLAN_2026-09-21.md) と [追加改善の計画・進捗](IMPROVEMENTS_2026-09-21.md) を参照。ビルド、テスト、サーバー起動による確認は利用者が実施する。

旧 `ROLE_PROTECTION_DESIGN.md` は設計当時の記録として残す。同文書の「コードは変更していない」という記述に対し、現在は役職保護コードが存在し、`ROLE_PROTECTION_PLAN.md` に実装済み・手動確認待ちと記録されている。今後の全面改良の仕様基準は本計画書群とし、既存コードにある機能を未実装と取り違えない。
