# MinecraftPluginTemplateの使い方

## 新しいプラグインを作る

1. `MinecraftPluginTemplate`フォルダを丸ごとコピーします。
2. コピーしたフォルダを、作りたいプラグイン名へ変更します。
3. `新規プラグイン開発プロンプト.md`を開き、設定欄を書き換えます。
4. プロンプト全文とコピーしたフォルダをAIへ渡します。
5. 開発完了後、`build.bat`をダブルクリックします。
6. `target`フォルダが自動で開くので、完成したJARをMinecraftサーバーの`plugins`フォルダへ入れます。
7. サーバーを再起動します。`/reload`は不具合の原因になりやすいため使用しません。

## 自分で名前を変更する場合

次の場所にある`MyPlugin`と`myplugin`を新しい名前へ変更します。

- `pom.xml`の`artifactId`と`name`
- `src/main/resources/plugin.yml`
- `src/main/java/com/example/myplugin/MyPlugin.java`
- Javaファイル先頭の`package com.example.myplugin;`

Javaのパッケージ名には英小文字、クラス名には半角英数字を使ってください。

## 必要な環境

- Windows 10
- Java 21
- SpigotまたはPaper 1.21系サーバー
- Maven、またはMavenプラグインが有効なIntelliJ IDEA

Mavenのコマンドを手入力する必要はありません。`build.bat`が利用可能なMavenを自動で探します。
