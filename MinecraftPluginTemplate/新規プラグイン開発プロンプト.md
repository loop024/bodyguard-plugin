# 新規Minecraftプラグイン開発プロンプト

以下をすべてコピーし、最初の設定欄だけ書き換えてAIへ送ってください。

```text
Windows 10、Java 21、Spigot 1.21.8向けのMinecraftプラグインを開発してください。

【設定】
プラグイン名: ここに名前を書く
メインコマンド: ここにコマンドを書く
作者名: ここに名前を書く
作りたい機能:
- ここに機能を書く
- ここに機能を書く

【使用するひな形】
この依頼と一緒に渡したMinecraftPluginTemplateフォルダを基準にしてください。
既存のpom.xml、build.bat、src構成を再利用し、プラグイン名に合わせてartifactId、finalName、Javaのパッケージ、メインクラス、plugin.ymlをすべて変更してください。

【必須条件】
- ビルドはMavenを使い、build.batをダブルクリックするだけで行えるようにする。
- コマンドプロンプト用の.batを使用し、PowerShell専用スクリプトは作らない。
- 完成したJARはtargetフォルダへ出力する。
- Spigot API以外のライブラリが必要ならpom.xmlへ追加し、理由も説明する。
- 外部ライブラリをJARへ同梱する必要がある場合はmaven-shade-pluginを使う。
- plugin.ymlへコマンドと権限を漏れなく登録する。
- 設定値は可能な限りconfig.ymlへ分離し、日本語コメントを付ける。
- プレイヤー向けメッセージは分かりやすい日本語にする。
- null、権限不足、コンソール実行、プレイヤー退出、プラグイン停止時を安全に処理する。
- サーバーのメインスレッドを長時間止める処理を作らない。
- データを保存する場合は、サーバー再起動後も復元できるようにする。
- 既存ファイルを確認してから編集し、不要なファイルを勝手に削除しない。
- 私が自分でテストするため、AIはテストやビルドを実行しない。
- 完成後は、変更したファイルと、初心者でもできる動作確認手順を日本語で説明する。

機能の仕様に小さな不足がある場合は、安全で一般的な動作を判断して実装してください。
保存形式やゲームバランスなど、後から変更しにくい重要事項だけは実装前に質問してください。
```
